급여정산 리체크 / 결과 확인

처음 사용하시나요?

급여 확정 전에 급여정산 엑셀이 맞게 작성됐는지 자동으로 대조하는 페이지입니다. 아래 순서대로 하면 5분 안에 끝납니다.

1

파일 3개 준비하기

  • 전월 급여정산 엑셀 (예: 9월 파일)
  • 금월 급여정산 엑셀 (예: 10월 파일)
  • 금월 매출시트: 구글시트에서 바로 읽거나, 파일 → 다운로드 → Microsoft Excel(.xlsx)로 받은 파일

파일 안의 월 표기가 아니라 파일명으로 월을 구분하니, 파일명에 월이 들어가 있는지 확인해 주세요.

2

파일 올리고 리체크 시작

  • 왼쪽 메뉴 파일 올리기에서 각 칸의 [파일 선택]을 누르거나 파일을 끌어다 놓습니다.
  • 매출시트는 구글시트에서 바로 읽기(Google 로그인 필요, 시트 보기 권한이 있는 계정) 또는 엑셀 파일 올리기 중 편한 쪽을 쓰세요.
  • 엑셀 암호를 입력하고 [리체크 시작]을 누릅니다. '이 브라우저에서 기억'을 켜두면 다음부터 입력하지 않아도 됩니다.

엑셀 파일은 이 브라우저 안에서만 열리고 어디에도 업로드되지 않습니다.

3

결과 확인하기

  • 위쪽 트레이너 탭을 누르면 그 트레이너의 안 맞는 회원만 보입니다. 이름 옆 숫자는 남은 건수입니다.
  • 맨 오른쪽 알바·직원 탭에서는 급여대장(직원) 검사 결과를 봅니다. 시급 누락, 전월 개인정보 그대로인 신규 입사자, 전월 근무시간을 그대로 복사한 경우를 찾아줍니다.
  • 각 줄의 [상세보기 ›]를 누르면 무엇이 안 맞는지와 계산식이 오른쪽에 열립니다.

색으로 상태를 표시합니다: 오류 확인필요 처리 완료 (아래 '표시 기준' 참고)

4

엑셀에서 고치고 다시 올리기

  • 오류 항목은 급여정산 엑셀에서 한꺼번에 고칩니다.
  • 결과 화면 위쪽 [수정 파일 다시 올리기]로 고친 파일만 바꿔 넣고 [다시 검사]를 누르면, 맞게 고쳐진 항목은 자동으로 처리 완료로 바뀝니다.
  • 확인필요 항목은 양도·환불처럼 정당한 사유가 있을 수 있는 건입니다. 고칠 게 아니라면 [상세보기]에서 [예외로 등록]하고 사유를 적어 주세요. 등록한 예외는 다음 달에 다시 묻지 않습니다.

표시 기준

오류숫자가 맞지 않아 엑셀에서 고쳐야 하는 항목 (1원·1회라도 다르면 오류)
확인필요양도·환불·이름 표기 차이처럼 사유 확인이 필요한 항목
처리 완료 예외 등록수정 파일로 맞는 것이 확인됐거나, 예외로 등록된 항목
진행 중남은 오류가 1건 이상
리체크 완료남은 오류가 0건 (확인필요가 남아 있어도 완료)

자주 묻는 질문

엑셀 파일이 서버에 저장되나요?

아니요. 파일은 지금 쓰는 브라우저 안에서만 열고 검사합니다. 어디에도 업로드되지 않습니다.

다른 컴퓨터에서 지난 리체크와 예외 기록이 안 보여요.

기록은 리체크한 컴퓨터의 브라우저에 저장됩니다. 같은 컴퓨터, 같은 브라우저에서 열어 주세요. 브라우저 기록을 지우면 함께 사라집니다.

"같은 파일일 수 있다"는 경고가 떠요.

전월과 금월 파일의 총수업과 신규회원 수가 똑같을 때 뜹니다. 금월 파일 대신 전월 파일을 복사만 해 둔 경우가 많으니, 파일을 다시 확인해 주세요.

구글시트 바로 읽기가 안 돼요.

로그인한 Google 계정에 그 매출시트를 볼 권한이 있는지 확인해 주세요. 안 되면 엑셀로 내려받아 [엑셀 파일 올리기]를 이용하면 됩니다.

매출시트에만 있는 결제가 '담당 미확인'으로 나와요.

매출시트의 결제자는 담당 트레이너와 다를 수 있어서 트레이너를 정하지 않고 보여줍니다. '전체' 탭에서 확인하고, 해당 트레이너의 급여정산 신규 목록에 추가해 주세요.

파일 올리기

전월·금월 급여정산과 금월 매출시트를 올리면 3단계 리체크를 자동으로 돌립니다.

전월 급여정산예: 9월
아직 선택 안 함
엑셀 파일(.xlsx)을 고르거나 이 줄에 끌어다 놓으세요
금월 급여정산예: 10월
아직 선택 안 함
엑셀 파일(.xlsx)을 고르거나 이 줄에 끌어다 놓으세요
금월 매출시트선택
구글시트 바로 읽기는 Google 로그인 후 사용할 수 있어요. [불러오기]를 누르면 Google 로그인 창이 열립니다. 로그인한 계정에 매출시트 보기 권한이 있어야 하고, 처음 한 번은 '시트 보기 허용'을 눌러 주세요. 시트는 읽기만 하고 수정하지 않습니다. 권한이 없다면 를 이용하세요.
아직 선택 안 함
구글시트에서 파일 → 다운로드 → Microsoft Excel(.xlsx)로 받은 파일을 고르거나 이 줄에 끌어다 놓으세요

💡
검사 후 엑셀에서 고친 파일은 결과 화면에서 다시 올리면 됩니다. 파일 안의 월 표기 대신 파일명으로 월을 판단합니다. 전월과 금월의 총수업·신규회원 수가 똑같으면 작업 안 된 사본일 수 있어 먼저 알려드립니다.
